# Last Minute

A web app that helps students and budget-conscious people find discounted food that's still good. Surplus meals, near-expiry products and last-minute deals from nearby businesses.

## Installation & Running

### Frontend

```bash
cd last-minute-frontend
npm install -g @angular/cli
npm i
npm run start
```

The app runs by default on `http://localhost:4200`.

### Backend

```bash
cd last-minute-backend
npm i
npm run dev
```

The backend runs on `http://localhost:4001`. It's an API-only server (no root route), so opening it directly in the browser shows "not found".

## Tech Stack

- Frontend: Angular, TypeScript, CSS
- Backend: Node.js, JavaScript, SQL
- Database: MSSQL
